# Proyecto Selo Arcano

## Descripción
¡Corra por el circuito, acorrale a los caminantes y active el Selo Arcano para absorber 1000 de energía en 3 rondas! Este es un juego de estrategia y velocidad donde cada movimiento cuenta para alcanzar tu objetivo de energía.

## Enemigos: Los Caminantes
Son entidades que se desplazan por el circuito. Tu objetivo es interceptar sus trayectorias y bloquear su movimiento para acorralarlos con éxito.

## Controles
*   Movimiento: Usa las teclas de dirección (flechas) o los controles en pantalla para guiar a tu personaje por el circuito.
*   Activar Selo Arcano: Presiona el botón de acción ('Espacio' o el icono en pantalla) cuando estés en la posición correcta para absorber la energía.
